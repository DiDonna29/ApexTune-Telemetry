# **App Name**: ApexTune Telemetry

## Core Features:

- Component Setup Manager: Adjustable digital forms to capture and save tire pressure, aerodynamics, and suspension values.
- State Persistence: Utilizes local storage to maintain car configurations between sessions without requiring an external database.
- Technical Bi-Lingual Engine: Seamlessly toggle between English and Spanish with accurate localization of high-end mechanical terms.
- Environmental Mode Switch: Integrated dark and light theme toggle to match track conditions or user preference.
- Performance Overview: A centralized dashboard to review and compare saved technical parameters in a grid-based cockpit layout.

## Style Guidelines:

- Light mode follows a professional precision aesthetic using a background of #EEEEEE with a clean #00ADB5 (Teal) accent.
- Dark mode implements a cockpit-night view using #222831 as the base with high-visibility #00FFF5 for primary status indicators.
- Primary headline and technical value font is 'Space Grotesk', providing a tech-heavy, scientific aesthetic.
- Secondary body font is 'Inter' for clear legibility during high-concentration racing tuning tasks.
- The interface is structured in modular pods and structured grids to mirror a racing simulator's Multi-Function Display (MFD).
- Swift, crisp transitions (no eases) to reinforce the sensation of high-performance technical equipment.
- Simplified monoline icons representing automotive engineering concepts like aero-downforce and mechanical grip.
